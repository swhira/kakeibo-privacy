1. サービス内容

本アプリは、投資と特別支出を分けて、貯蓄（収入−支出−投資）と変動費を見える化する家計簿です。銀行口座の自動連携はありません。記録は原則として利用者の端末内に保存されます。

  • 収入・支出・投資の記録、予算、分析グラフ
  • ボーナス決裁、定期支出、資産記録
  • 家計診断コメント、月次PDFレポート（一部はプレミアム）
  • 任意のサインイン（Sign in with Apple）による端末間同期
  • 手動実行のAI家計診断（要約のみ送信。プレミアム）

本アプリは投資助言、税務助言、金融商品の推奨を行いません。表示される数値や診断は、利用者が入力したデータに基づく参考情報です。

3. 無料機能とプレミアム

3.1 無料で使える範囲

記録、貯蓄・変動費・グラフ、予算、ボーナス決裁、定期支出、資産タブ、CSV取込、手動バックアップ、診断コメントの一部（先頭1件）は、無料で利用できます。

3.2 プレミアム機能

次の機能は、有料のプレミアム（自動更新サブスクリプション）で提供します。

  • 家計診断コメントの全件
  • AI診断（直近数ヶ月の比較と節約のヒント。月あたりの利用回数上限あり）
  • 月次PDFレポートの作成・共有
  • 端末間同期（新規ユーザー）

機能の追加・変更・廃止は、合理的な範囲で行うことがあります。

3.3 既存ユーザーの同期（据え置き）

本アプリの初回公開時、端末間同期は無料でした。プレミアム課金開始時点より前にアカウントを作成し、同期データを保存していた利用者については、端末間同期を引き続き無料で利用できます。この据え置きは、当該アカウントに限ります。

4. 料金・課金・解約

4.1 購入方法

プレミアムの購入・復元・解約は、Apple の App Store / StoreKit を通じて処理されます。開発者はクレジットカード番号等の支払情報を取得しません。表示価格は App Store の表示に従い、地域や税制により異なる場合があります。

日本における目安（アプリ内課金）:

  • 月額プラン: 400円（自動更新、無料トライアルなし）
  • 年額プラン: 4,000円（自動更新、新規購読者に14日間の無料トライアル）

年額の無料トライアル期間中に解約した場合、料金は発生しません。トライアル終了後は、年額プランの料金が課金されます。

4.2 自動更新

購読は、利用者が解約しない限り、各期間の終了時に同じ期間で自動更新されます。更新日前の24時間以内に、更新分が課金されます。

4.3 解約方法

サブスクリプションの解約・プラン変更は、Apple ID の設定から行ってください（本アプリ内の「サブスクリプションを管理」からも同じ画面を開けます）。

本アプリのアンインストール、サインアウト、アカウント削除だけでは、サブスクリプションは解約されません。課金を止めたい場合は、必ず Apple ID 側で解約してください。

4.4 復元

別の端末で同じ Apple ID を使う場合は、本アプリの「購入を復元」から権利を復元できます。

4.5 返金

返金の可否は Apple の方針に従います。開発者が個別に返金処理を行うことはできません。

5. 解約後・アカウント削除後のデータ

5.1 サブスクリプション解約後

  • 端末内の家計データは削除しません。無料機能は引き続き利用できます。
  • プレミアム機能（診断全件、AI診断、月次PDF、新規の同期書き込み）は利用できなくなります。
  • クラウド上の同期データは、直ちに削除しません。読み取りと削除は可能です。新規の書き込みは停止します。
  • クラウドデータの保持期間の上限は設けません。アカウント削除またはサービス終了時に削除します。

5.2 アカウント削除

設定からアカウントを削除すると、サーバー上のアカウントと同期データは削除されます。端末内データは、利用者が削除またはアンインストールするまで残ることがあります。アカウント削除は、Apple のサブスクリプションを自動では解約しません。
